# OSM-v18.0-installer

Old version for v18.0, if you can't install v19.0 and the functions of 18.0 are good enough, you can use the installer here (it automatically fixes broken dependancies for OSM v18.0). The install script and the client install script from this version need to be run with "source" as they don't update their variables otherwise.

Once OSM v18.0 or the client (depending if on the OSM machine or another) are installed, you can switch to branch v19.0 since all the scripts there should work in OSM v18.0.
